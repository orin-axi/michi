*Suggested fix* — append to `scope`:
&gt; "The `is_error_case` flag on each criterion below denotes a degenerate-but-valid edge-of-domain input (empty content, empty hint, max_chars=0, the hard-cap region, or the no-panic matrix) that this crate's Result-less &amp;str-typed API cannot reject — not an invalid input rejected by the system.
