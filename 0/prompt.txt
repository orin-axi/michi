# Agentic Pipeline Library — Rust Crate Spec
## Pipeline Execution · Resilience · Fuzzy Matching · Caching
> A surface-agnostic Rust library for building agentic workflows.  
> Consumed by CLI binaries and MCP servers alike — neither surface leaks into core.
---
## Design Principles
- **No surface assumptions in core.** Core modules have zero knowledge of TTYs, MCP protocol,
  exit codes, or stdin/stdout. All surface concerns live in opt-in adapter modules.
- **Trait-bounded I/O.** Output, disambiguation, and checkpoint persistence are injected via
  traits. Consumers wire in the right implementation; core never calls `println!` or touches disk.
- **Noop-safe defaults.** Every injected dependency has a zero-cost noop default so the library
  is usable without configuring anything upfront.
- **Typed events over callbacks.** The pipeline emits `AgentEvent` values to an `OutputSink`.
  Surface adapters decide what to do with them — spinners, JSON lines, MCP response bodies, nothing.
- **Phased telemetry.** `TelemetryProvider` is a trait with a `NoopProvider` default.
  Real OTel is a 1-line swap when infrastructure exists.

## 1. Error Model
```rust
// src/error.rs
/// Wraps sensitive values so they are never printed in logs or debug output.
pub struct Sensitive<T>(T);
impl<T> Sensitive<T> {
    pub fn new(value: T) -> Self { Self(value) }
    pub fn expose(&self) -> &T { &self.0 }
}
impl<T> fmt::Debug   for Sensitive<T> { fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result { f.write_str("[REDACTED]") } }
impl<T> fmt::Display for Sensitive<T> { fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result { f.write_str("[REDACTED]") } }
/// Two-class error distinction.
/// User errors are safe to surface verbatim. Internal errors log full context
/// but show only a terse message to the consumer.
#[derive(Debug, Clone, PartialEq)]
pub enum ErrorClass {
    /// Caused by caller input or expected external conditions (no-match, bad arg).
    /// Surface the message. No stack trace.
    User,
    /// Caused by infrastructure: I/O, network, timeouts, cache corruption.
    /// Log full context internally; show terse message externally.
    Internal,
}
#[derive(Debug, thiserror::Error)]
pub enum AgentError {
    #[error("HTTP {status}: {message}")]
    Http {
        status: u16,
        message: String,
        retryable: bool,
        retry_after: Option<Duration>,
    },
    #[error("Timeout after {elapsed:?}")]
    Timeout { elapsed: Duration },
    #[error("Step '{id}' failed: {source}")]
    StepFailed { id: String, #[source] source: Box<AgentError> },
    #[error("Circuit open for '{name}', retry after {retry_after:?}")]
    CircuitOpen { name: String, retry_after: Duration },
    #[error("No match for '{query}'")]
    NoMatch { query: String },
    #[error("Ambiguous match for '{query}': {count} candidates")]
    AmbiguousMatch { query: String, count: usize },
    #[error("Cycle detected in pipeline graph: {cycle:?}")]
    CyclicDependency { cycle: Vec<String> },
    #[error("Operation cancelled")]
    Cancelled,
    #[error("Cache: {0}")]
    Cache(String),
    #[error(transparent)]
    Io(#[from] std::io::Error),
}
impl AgentError {
    pub fn class(&self) -> ErrorClass {
        match self {
            Self::NoMatch { .. }
            | Self::AmbiguousMatch { .. }
            | Self::Cancelled            => ErrorClass::User,
            _                            => ErrorClass::Internal,
        }
    }
    pub fn is_retryable(&self) -> bool {
        match self {
            Self::Http { retryable, .. } => *retryable,
            Self::Timeout { .. }         => true,
            _                            => false,
        }
    }
    pub fn retry_after(&self) -> Option<Duration> {
        match self {
            Self::Http { retry_after, .. }       => *retry_after,
            Self::CircuitOpen { retry_after, .. } => Some(*retry_after),
            _                                    => None,
        }
    }
}
```

## 5. Resilience
```rust
// src/resilience/policy.rs
#[derive(Debug, Clone)]
pub struct ResiliencePolicy {
    pub max_attempts: u32,              // default: 3
    pub initial_backoff: Duration,      // default: 1s
    pub max_backoff: Duration,          // default: 30s
    pub backoff_multiplier: f64,        // default: 2.0
    pub per_attempt_timeout: Duration,  // default: 30s
    pub circuit: Option<CircuitBreakerConfig>,
}
impl Default for ResiliencePolicy {
    fn default() -> Self {
        Self {
            max_attempts: 3,
            initial_backoff: Duration::from_secs(1),
            max_backoff: Duration::from_secs(30),
            backoff_multiplier: 2.0,
            per_attempt_timeout: Duration::from_secs(30),
            circuit: None,
        }
    }
}
/// Surface-agnostic: emits RetryScheduled/CircuitOpened to sink rather than
/// printing directly. The sink decides what to do with them.
pub async fn with_resilience<T, F, Fut>(
    policy: &ResiliencePolicy,
    label: &str,
    sink: &Arc<dyn OutputSink>,
    cancel: CancellationToken,
    f: F,
) -> Result<T, AgentError>
where
    F: Fn() -> Fut + Send,
    Fut: Future<Output = Result<T, AgentError>> + Send,
{
    let mut attempt = 0;
    loop {
        attempt += 1;
        let result = tokio::select! {
            r = tokio::time::timeout(policy.per_attempt_timeout, f()) => {
                r.map_err(|_| AgentError::Timeout { elapsed: policy.per_attempt_timeout })
                 .and_then(|inner| inner)
            }
            _ = cancel.cancelled() => return Err(AgentError::Cancelled),
        };
        match result {
            Ok(v) => return Ok(v),
            Err(e) if !e.is_retryable() || attempt >= policy.max_attempts => return Err(e),
            Err(e) => {
                let wait = e.retry_after().unwrap_or_else(|| {
                    let base = policy.initial_backoff.as_secs_f64()
                        * policy.backoff_multiplier.powi(attempt as i32 - 1);
                    Duration::from_secs_f64(base.min(policy.max_backoff.as_secs_f64()))
                });
                sink.emit(AgentEvent::RetryScheduled {
                    label: label.to_string(),
                    attempt,
                    max: policy.max_attempts,
                    wait,
                });
                tokio::select! {
                    _ = tokio::time::sleep(wait) => {}
                    _ = cancel.cancelled()        => return Err(AgentError::Cancelled),
                }
            }
        }
    }
}
```

### Disambiguator trait + resolver
```rust
// src/fuzzy/resolver.rs
/// Injected disambiguation strategy.
/// Core never knows whether this shows a TTY prompt, returns candidates to an
/// LLM, logs a warning, or always returns None.
#[async_trait]
pub trait Disambiguator: Send + Sync {
    async fn resolve<T: Clone + Send + Sync>(
        &self,
        query: &str,
        candidates: Vec<Match<T>>,
    ) -> Option<T>;
}
/// Always returns None — caller receives AmbiguousMatch and handles it.
pub struct NoDisambiguator;
#[async_trait]
impl Disambiguator for NoDisambiguator {
    async fn resolve<T: Clone + Send + Sync>(&self, _: &str, _: Vec<Match<T>>) -> Option<T> {
        None
    }
}
pub struct FuzzyResolver {
    matcher: FuzzyMatcher,
    disambiguator: Arc<dyn Disambiguator>,
}
#[derive(Debug, Clone)]
pub enum Resolution<T> {
    Exact(T),       // exact string match — no fuzzy cost
    Resolved(T),    // single fuzzy match above threshold, auto-selected
    Chosen(T),      // disambiguator returned a choice
    NotFound,       // nothing cleared threshold
}
impl FuzzyResolver {
    pub fn new(config: MatcherConfig, disambiguator: Arc<dyn Disambiguator>) -> Self;
    /// Resolution algorithm:
    /// 1. Exact match (case-insensitive ==)     → Exact
    /// 2. Prefix match (starts_with)            → Exact
    /// 3. match_all():
    ///    a. 0 results                           → NotFound
    ///    b. 1 result, score ≥ threshold         → Resolved (auto, no prompt)
    ///    c. multiple or score borderline        → disambiguator.resolve()
    ///       → Some(item)                        → Chosen
    ///       → None                              → Err(AmbiguousMatch)
    pub async fn resolve<T>(
        &mut self,
        query: &str,
        candidates: &[T],
        key_fn: impl Fn(&T) -> &str,
    ) -> Result<Resolution<T>, AgentError>
    where
        T: Clone + Send + Sync;
}
```

## Open Questions
1. **Crate name.** `agent-pipeline`is a placeholder. Should reflect that it's pipeline execution
   + resilience + fuzzy + cache — not just a pipeline runner.
2. **`PipelineResult` MCP serialization.** The `status/completed/failed` shape maps cleanly to
   a tool response body but the exact schema (field names, error format) should be decided by
   the consumer, not the library. A `PipelineResult::to_json()` helper risks encoding opinions.
   Leave serialization to the adapter layer.
3. **Real OTel provider.** The `TelemetryProvider` trait is intentionally minimal. A real
   `OtelProvider` wrapping `opentelemetry` SDK belongs in an optional `telemetry` feature or a
   separate companion crate — keeps the core dep tree clean.
4. **Circuit breaker day-one scope.** The `CircuitBreakerConfig` is in the type signature but
   the impl can ship as `todo!()` in v0.1. The field is `Option<>` so it's a non-breaking add.
5. **`DiskCacheConfig.root`** has no default — the library doesn't know where the consumer
   wants to write. CLI adapter can default to an XDG-aware path; MCP servers will typically
   leave disk caching off (`disk: None`).
